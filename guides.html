Guides

Small writing habits that make notes more useful.

A good note does not need to be complicated. These short guides explain practical ways to capture information and keep it usable later.

1. Turn a quick note into an actionable list

Start with the information you do not want to forget. Then separate facts, decisions, and actions. For example, a meeting note can contain three sections: decisions already made, questions that remain open, and the next actions that someone needs to complete.

Keeping these categories separate makes a note easier to scan later. Use short lines for individual tasks and longer paragraphs only when context is genuinely useful.

2. Use a focused writing session

Before starting, decide what a successful session means. It might be writing 300 words, preparing a first draft, or finishing one section of a document. During the session, keep unrelated tasks outside the writing area.

Focus Mode and Fullscreen are useful for different reasons: Focus Mode reduces interface distractions, while Fullscreen removes the surrounding browser chrome. Choose the lighter option when you still need access to your normal workspace.

3. Keep important notes recoverable

Automatic local saving is useful for active work, but it should not be treated as a complete backup strategy. For information that matters, create an explicit version or download a copy and keep it somewhere appropriate.

A simple habit is to save a version before making a major change. That creates a clear checkpoint that you can return to if the new direction does not work.

4. Keep sensitive information out of shared devices

Browser-based storage is convenient, but a shared computer is still a shared environment. Avoid writing passwords, recovery codes, financial credentials, or other highly sensitive information into a general-purpose notes application on a device that other people can access.

For sensitive credentials, use a dedicated password manager or another security product designed specifically for that purpose.
