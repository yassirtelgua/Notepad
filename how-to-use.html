How to use

Start writing in seconds.

Notepad is intentionally simple. Open the app, write your note, and use the toolbar only when you need an additional tool.

Quick start

  1. Open the app.
    Choose Notepad from the navigation and place your cursor in the writing area.
  2. Write normally.
    Your note is automatically stored in your browser while you work.
  3. Format when needed.
    Use A− or A+ to adjust text size, or use the bold, italic, and heading controls.
  4. Save a version.
    Use Ctrl + S or Version History when you want a recoverable checkpoint.
  5. Change your reading environment.
    Read Mode gives you a clean reading view; Focus Mode removes interface distractions; Fullscreen uses the entire browser window.
  6. Export or copy.
    Download the note as a file or copy its contents when you are ready to use it elsewhere.

Keyboard shortcut

Ctrl + S saves the current note as a version. The browser's normal save-page behavior is not used for this shortcut.

What happens to my note?

The current version stores your note in the browser's local storage. This means the note is tied to the browser and device where you wrote it. Clearing site data, using a different browser, or switching devices can remove or separate that locally stored copy.
